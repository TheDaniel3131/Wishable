# UUID Generator — Nuxt 3

A sleek UUID generator built with Nuxt 3.

## Features

- Generate v1 (timestamp-based) and v4 (random) UUIDs
- Adjustable count (1–20 at a time)
- Uppercase toggle
- One-click copy per UUID, or copy all at once

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build for production

```bash
npm run build
npm run preview
```
