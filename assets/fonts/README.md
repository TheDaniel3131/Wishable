# Fonts

Place `MaterialSymbolsOutlined.ttf` here.

This is the Material Symbols (Outlined) variable font, referenced by
`pubspec.yaml` under the `MaterialSymbolsOutlined` family and used by
`lib/theme/app_theme.dart` (`AppIcons`) to render the app's icon set (R13.4).

Download the latest `MaterialSymbolsOutlined[FILL,GRAD,opsz,wght].ttf` from the
Material Symbols repository and save it in this directory as
`MaterialSymbolsOutlined.ttf`.
