# Web platform assets

The Drift web backend (`WasmDatabase.open` in `lib/data/connection/web.dart`,
task 2.2) requires two WebAssembly/worker assets, which are shipped here:

- `sqlite3.wasm` — SQLite compiled to WebAssembly (`\0asm` module).
- `drift_worker.js` — the Drift web worker that runs the database off the main
  thread and selects OPFS (preferred) or IndexedDB storage.

## Versions

The assets are pinned to match the resolved package versions so the loaded
binary matches the Dart bindings:

- `sqlite3.wasm` — from the `sqlite3.dart` release matching `sqlite3`
  (currently `2.4.6`):
  <https://github.com/simolus3/sqlite3.dart/releases>
- `drift_worker.js` — from the `drift` release matching `drift`
  (currently `2.31.0`):
  <https://github.com/simolus3/drift/releases>

When bumping the `drift` or `sqlite3` dependency, re-download the matching
assets from the release pages above and replace the files in this directory.

## Other web assets

The icon PNGs referenced by `manifest.json` (`icons/Icon-192.png`, etc.) and
`favicon.png` are generated by `flutter create .`; drop in placeholders or
regenerate them with the Flutter SDK.
